# 💰 Кредитный калькулятор

![HTML5](https://img.shields.io/badge/HTML5-✅-orange.svg)
![CSS3](https://img.shields.io/badge/CSS3-✅-blue.svg)
![Chart.js](https://img.shields.io/badge/Chart.js-3.9.1-green.svg)

Интерактивный веб-калькулятор для расчета аннуитетных платежей по кредиту с визуализацией графика выплат.

## 📊 Функциональность

- ✅ Расчет ежемесячных аннуитетных платежей
- ✅ Визуализация графика выплат (Chart.js)
- ✅ Детальная таблица платежей по месяцам
- ✅ Адаптивный дизайн для всех устройств
- ✅ Интерактивные ползунки и валидация ввода

## 🛠 Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Библиотеки**: Chart.js для графиков
- **Адаптивность**: CSS Grid, Flexbox, Media Queries

## 📁 Структура проекта
Файлы находятся в папке `credit/src/`:
- `index.html` — Главная страница
- `style.css` — Стили и анимации
- `script.js` — Логика калькулятора

## 🚀 Как запустить локально
Так как это чистый Frontend, вам не нужен сервер. Просто скачайте папку `src` и откройте файл `index.html` в любом браузере.

---
> 💡 **Зачем это нужно:** Практика фронтенд-разработки и работы с библиотекой Chart.js. Интересной задачей была синхронизация ползунков и полей ввода для создания плавного и отзывчивого интерфейса.
